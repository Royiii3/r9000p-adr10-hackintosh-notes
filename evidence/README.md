## 证据层级

- **用户实机反馈：** 菜单等待明显改善、进入桌面、解除 CPU 限制后 Panic、最后删除 macOS。
- **原始文件记录：** 已保存配置、驱动安装日志、读取对照、账户完成状态。能复查当时写了什么、执行到哪一步。
- **macOS 端审计报告：** 报告记录了 Metal、3D、视频测试及设备状态，但对应全部原始测试源码和输出仍在后来删除的 macOS 用户目录中，本公开仓库没有完整原样收录。不能将它包装成第三方独立认证或性能评测。
- **上游文档 / Issue：** 用于参数解释和相近案例。其他人的机型和结果不等于本机结果。
- **未确认：** 精确 Panic 根因、`cpus=12` 结果、Above 4G 实际开关、完整睡眠/外设验收。

## 已脱敏的内容

移除或替换了作者用户名、完整序列号、MLB/ROM、个人主目录路径、磁盘/卷 UUID、完整 MAC 地址、内部日志的本机绝对链接等。通用的 Apple NVRAM GUID、PCI ID、MMIO 地址和上游提交号保留，因为它们不是作者的个人设备身份，且与排障有关。

原审计报告中的本机文件超链接已经转成路径标签，避免公开稿留下点不开的私人文件路径。审计报告正文保留“当时曾通过哪些测试”的边界；后续删除系统不会将这些历史记录自动改写为新的实测。

这次不附原始现场照片：部分照片包含人物反射、环境或设备标识，文字证据已经覆盖主要错误和步骤。后续若添加图片，应逐张检查再发布。
