# EFI 与附件归档说明

[返回首页](../README.md) · [配置副本](../configs/README.md) · [精选日志](../evidence/logs/README.md)

公开稿的 Git 文件中保留配置、差异、日志和 [EFI 文件清单](efi-desktop-manifest.json)。完整 EFI ZIP 保留本地，不作为公开下载附件；各组件的准确版本、源码与获取入口随清单公开。

## 完整 EFI 的范围

来源是 `EFI-STABLE-20261023` 备份，标签里的 STABLE 只是当时的备份名称。它对应 `cpus=1` 曾进入桌面的基线，仍有多核、无线、声音等未完成的问题，不能理解为日用稳定版本。

附件保留 `EFI/BOOT`、`EFI/OC`、驱动、ACPI、内核扩展和资源目录。所有 plist 中的个人 SMBIOS 身份已处理，压缩包内附文件清单与上游说明。脱敏之后没有再启动验证。

它不包含 macOS 恢复镜像、完整安装器、已安装的 NVIDIA 驱动包、NVIDIA/GSP 固件、账户数据库或个人文件。文件清单中的版本来自各组件元数据；这本身不能证明所有二进制均由同一源码版本构建。

## 发布状态

已补齐能确认的第三方许可文本和实际下载来源，具体见 [组件表与核对结果](../THIRD-PARTY-NOTICES.md)。AMFIPass、AppleMCEReporterDisabler、USBToolBox/UTBDefault、OcBinaryData 中的文件系统驱动及资源，仍未能确认覆盖实际载荷的再分发条款；不能用父项目许可代替。GPL/APSL 组件的完整对应源码交付材料也未随二进制打包，因此完整历史 EFI 不公开。这里的“未能确认”不等于认定原作者禁止分享。

需要比较配置的读者可以直接阅读 [4 份脱敏配置与差异](../configs/README.md)，再从清单列出的上游按版本获取组件。不要将同名机器视为完全相同的硬件，也不要把获取清单当作一键安装保证。

配置中的序列号等字段需要读者自行生成，不能复制作者身份。菜单中的 “Read-only checks” 只是当时的 Shell 名称，并不限制 Shell 能执行的操作。不要把整包覆盖到 Windows 内置 EFI 分区。

本仓库的目的是帮助复盘与比较配置，不承诺在另一台同名机器上启动，更不把未记录的 `cpus=12` 测试列为成功。
